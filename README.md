# 高校情報Ⅰ 動画のデータ量計算ドリル 
## 🎥📊高校情報Ⅰ「デジタルデータの表現・動画メディアの計算」を効率的に学習・演習できる、Webベースのインタラクティブ教材アプリケーションです。
### 🌟 主な機能・特徴🎯 3段階の難易度別演習（自動生成問題）初級: 映像のみ・非圧縮の基本計算問題。中級: 動画のデータ圧縮率（$1/N$）を考慮した定期テストレベル。上級: 音声トラック（$\text{kbps}$ 指定）を含めた実践的な複合計算問題。
### 💡 ステップバイステップ計算解説「1フレーム（静止画）」→「1秒間」→「全再生時間」→「圧縮適用」→「音声加算」→「単位換算」の思考順序に沿って、数式と解説をカード形式でわかりやすく表示。計算公式が確認できるヒント機能を搭載。
### ⚙️ 単位換算基準のトグル切替日本の教科書で一般的な $1\text{ KB} = 1000\text{ Bytes}$（SI接頭辞）と、情報理論で用いられる $1\text{ KB} = 1024\text{ Bytes}$（2の累乗）をワンクリックで切替可能。
### 🎛️ リアルタイム動画データ量シミュレーター解像度（SD, HD, Full HD, 4K）、色深度、フレームレート、動画の長さ、圧縮率のスライダーや数値を変更することで、データ量の変化をリアルタイムに体験。
### 🏆 学習スコア・連続正解（ストリーク）追跡挑戦数、正解数、正答率、連続正解数を追跡。正解時には紙吹雪（Confetti）によるアニメーション演出でモチベーションを維持。
### ⌨️ 快適なユーザー体験（UX）入力欄での Enter キー操作によるスムーズな回答送信・「次の問題へ進む」の連続回答フローに対応。レスポンシブ対応（PC・タブレット・スマートフォンで利用可能）。
## 🛠️ 使用技術 (Tech Stack)Frontend: HTML5, JavaScript (ES6+ Vanilla JS)Styling: Tailwind CSS (via CDN)Icons: Font Awesome 6Animation Effect: Canvas Confetti
## 🚀 使い方 / 動作方法本アプリケーションはビルド処理が不要な単一HTMLファイル（Single File HTML）で構成されています。このリポジトリをクローンまたはZIP形式でダウンロードします。git clone https://github.com/your-username/video-data-calculator.git
index.html をお好みのブラウザ（Google Chrome, Edge, Safari など）で直接開くだけで動作します。
